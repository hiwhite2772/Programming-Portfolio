## 🧠 Bài toán: Cộng hai số biểu diễn bằng Linked List
### 📌 Mô tả

- Bạn được cho hai danh sách liên kết không rỗng l1 và l2, biểu diễn hai số nguyên không âm.

- Các chữ số được lưu theo thứ tự ngược (reverse order).
- Mỗi node chứa một chữ số (0–9).
- Hai số không chứa số 0 ở đầu, trừ khi chính nó là số 0.

- Hãy viết hàm để cộng hai số này và trả về kết quả dưới dạng một danh sách liên kết, cũng theo thứ tự ngược.

### 📥 Input
- l1: Linked list biểu diễn số thứ nhất  
- l2: Linked list biểu diễn số thứ hai
### 📤 Output
- *Trả về linked list biểu diễn tổng của hai số*
#### 📌 Ví dụ 1
- Input:
    - l1 = [2, 4, 3]  
    - l2 = [5, 6, 4]

- Output:  [7, 0, 8]

- Giải thích:  342 + 465 = 807  
→ kết quả lưu ngược: 7 → 0 → 8

#### 📌 Ví dụ 2
- Input:
    - l1 = [0]  
    - l2 = [0]

- Output:
[0]

#### 📌 Ví dụ 3
- Input:
    - l1 = [9, 9]  
    - l2 = [1]

- Output:  [0, 0, 1]

- Giải thích:  99 + 1 = 100  
→ lưu ngược: 0 → 0 → 1

### ⚙️ Yêu cầu
- Thời gian: O(n)  
- Không được chuyển linked list thành số nguyên rồi cộng trực tiếp  
- Phải xử lý carry (số nhớ)
### 💡 Gợi ý
- Duyệt đồng thời hai linked list  
- Dùng biến carry để lưu số nhớ  
- Tạo node mới cho từng chữ số kết quả
